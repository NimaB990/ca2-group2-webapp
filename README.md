# Group 02 Cloud Showcase

A static website created for the NDT Cloud Computing CA02 project. The site introduces the Group 02 team and presents key ideas and benefits of cloud computing.

## Pages

- **Home** (`index.html`) - Project introduction and links to the main sections.
- **Team** (`team.html`) - Group members and student IDs.
- **Cloud** (`cloud.html`) - A summary of cloud computing concepts.
- **Contact** (`contact.html`) - A form for sending a message.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No build tools or package installation are required.

## Run locally

1. Clone or download this repository.
2. Open `index.html` directly in a browser, or serve the folder with a local web server.

For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Project structure

```text
.
├── index.html
├── team.html
├── cloud.html
├── contact.html
├── style.css
└── script.js
```

The contact form uses a `mailto:` link and therefore requires a configured desktop email client to submit messages.
